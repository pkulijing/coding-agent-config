# 开发会话标题自动化

## 背景

用户通过 Codex 桌面 App 和手机 App 的远程开发功能工作，希望从会话列表直接辨认开发轮次与完成状态。用户明确要求开始实现该能力。

## 需求

- 确定开始一轮开发后，将当前会话标题设置为 `r<N>-<中文描述>`，例如 `r31-修复视频卡顿`。
- 开发完成后，将同一会话标题设置为 `r<N>-<中文描述>-已完成`。
- 接入已有 `/start`、`/finish`，平时无需用户手动改名；手机远程使用时不增加手机端配置。
- 修改实际会话元数据，不依赖回复文案影响自动标题生成。

## 范围与边界

- 目标是 Codex 原生会话及实际运行任务的主机；CC 不假设支持同一接口。
- 复用现有 App Server，不启动、重启或升级服务，不开放网络端口，不直接改写 Codex 数据库或聊天记录。
- 准确定位当前会话；缺少会话 ID 或连接失败时明确报告，不猜测其他会话，也不将改名失败说成成功。
- 标题更新失败不撤销开发成果；开发完成状态必须按工作流实际结果设置。
- 桌面与手机的显示刷新需单独验证；协议请求成功不能等同于两端已显示。

## 已核实的环境

- 本机 CLI 为 `0.167.1`，运行中的 App Server 为 `0.169.0`。
- 本机 `codex app-server daemon version` 返回运行中服务的控制 socket 路径。
- 当前进程提供 `CODEX_THREAD_ID`。
- 经现有 Unix socket 完成 WebSocket 握手和 `initialize` / `initialized`，`thread/read` 成功返回相同的当前会话 ID；不读取会话正文。
- 尚未对真实会话执行改名，尚未验证桌面和手机的标题刷新。
