# lark-cli 个人约定

创作飞书云文档或处理 lark-cli 授权时读取。具体命令与资源路由使用对应 lark skill，不在此维护 CLI 参数副本。

## 文档署名

创建云文档时，默认在标题下、首个正文块前插入 quote：

> ⚡ Crafted with lark-cli · <YYYY-MM-DD>

日期取创建当天。正式或对外严肃文档不宜署名时可省略。

## 内容与验收

- 图表优先使用平台可编辑形式；精确版式才考虑 SVG 等中间格式。
- 修改后回读目标文档或画板，核对位置、层序、箭头与文字；源文件渲染正确不等于线上产物正确。
- 路径、锚点、导入与画板转换参数按当前 lark-doc/lark-whiteboard skill 和 CLI 帮助核实，不沿用历史版本的补丁配方。

## 授权

- 最小 scope 授权，不按 `--domain` 打包扩大权限。将本轮必要 scope 一次收集后发起授权，避免反复扫码；缺权限不擅自改用更高权限身份。
- 预检优先使用读操作或明确无副作用的 dry-run。审批中的 scope 与可用 scope 如何拆分，以当前授权返回与 lark-shared 流程为准。
- 迁移机器时验证身份与授权，不拷贝凭据文件冒充完成认证。
- 无人值守通知优先使用已授权 bot 身份；user token 失效应走既定告警出口，不能静默连续失败。该约定不额外授权发送消息。
