# 飞书 bot 后端

仅适用于 lark-oapi 长连接和事件/卡片回调开发；文档创作与 CLI 授权另见 `playbooks/lark.md`。

## 事件处理契约

- 接入前核对当前事件的重试、确认与唯一标识语义。写操作必须处理重复投递与部分失败，不依赖回调“通常只到一次”。
- 并发判重与状态记录需原子化；内存去重必须有界。跨进程、重启后仍不能重复的操作，应在持久业务层保证幂等。
- 区分已接收、处理中、已完成与失败；不能在处理前放进永久去重集合后让失败事件永远无法重试。
- 验证重复、并发与处理失败后的恢复，不只验证收到一次消息。

## 部署前提

事件与卡片回调的后台订阅、权限和发布状态属于部署验收。卡片点击无回调时先核对订阅与实际事件日志，再检查业务处理；连接成功不证明事件已订阅。
