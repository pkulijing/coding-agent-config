name: example-status
description: 查询现有 CLI 的状态并解释结果；不用于部署、删除或修改配置。
---

在本项目根目录调用已经安装的 `example-cli`，查询并解释状态。

1. 先确认项目根与 CLI 可用；运行 `example-cli --help`、`example-cli status --help` 核实当前版本的参数、查询范围和退出码语义。命令不存在就报告缺项与项目提供的安装指引，不猜安装来源。
2. 确认 `status` 是只读操作后，执行 `example-cli status`。仅使用实际帮助中存在的参数，用户参数保持原有语义与参数边界，不把用户文本拼成 shell 代码。缺少只有用户知道的范围或配置就询问。
3. 同时检查退出码与响应内容。非零退出、响应体错误或范围不完整都不能报成功；0 条结果须核实查询范围，不能直接断言资源不存在。解释实际结果，保留关键诊断且不泄露凭据。

skill 只调用 CLI 并解读输出，不 import 本体代码，不复刻其解析、编排或业务规则。新增写操作 skill 前先核实原生预览能力：支持 dry-run 则先预览，列明目标与影响并取得必要授权后再执行；不支持则明确说明，不能编造参数。

后续操作只指向用户可选择的入口，不硬调用另一个 skill；CC 的插件命名空间与 Codex 的 `$skill` 名称分别按实际安装入口展示。
